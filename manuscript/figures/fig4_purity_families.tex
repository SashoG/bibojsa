% fig4_purity_families -- best unfiltered heralded purity (adaptive window)
% along each GVM family, versus pump wavelength.  The horizontal guide is the
% sinc-limited value of symmetric GVM on the adaptive window (point D, 0.83);
% its band-independent limit is 0.80 (manuscript Sec. 4.4), so it is labelled
% "EPM sinc value", not "ceiling" (v0.8, 25 Sep 2026).
% v0.9 (14 Oct 2026, REVIEW_2026-10-14 item C/Fig. 4): the oeo panel is drawn
% on 0.70-1.0 (its data occupied the top fifth of a 0-1 axis); members whose
% idler lies beyond the 2.6-um absorption onset (inwin = 0 in the CSV) are
% open markers; the type-I panels are markers only (the (L, bandwidth)
% optimum of a near-triple JSA hops between grid corners, so connecting
% lines suggested trends that are not there) and use the type-I x-range.
% Data: data/purity_<seq>_<target>.csv
